# China Battery Lens — 디자인 명세 (Stitch 입력용)

**레퍼런스: [iea.org](https://www.iea.org/)** — 국제에너지기구의 기관 리서치 퍼블리셔 스타일.
Stitch 등 UI 생성 도구에 붙여 넣어 화면을 만들 때 쓴다.

---

## 1. 제품과 방향

중국 배터리 셀·양극재·음극재 기업의 뉴스와 거래소 공시를 수집해, **한국어 팩트 리포트·기업 시계열·기업 비교**로 보여주는 내부 리서치 도구. 사용자는 한국 배터리·소재 회사의 전략/기획 담당자다.

**목표 톤 — IEA를 따른다:**
기관이 내는 **에너지 리서치 퍼블리케이션**. 흰 바탕에 검정 활자, 강조는 파랑 하나. 장식·그라데이션·그림자 없음. 카테고리 태그와 얇은 구분선으로 구조를 만들고, 활자 크기와 굵기만으로 위계를 세운다. 신문·연구보고서에 가깝고 SaaS 대시보드처럼 보이지 않는다.

**IEA에서 가져올 것 / 버릴 것**

| 가져온다 | 버린다 |
|---|---|
| 흑·백·회색 + 파랑 하나의 절제된 팔레트 | 파스텔·다색 카드 |
| 카테고리 태그 알약 + 굵은 제목 조합 | 아이콘 장식, 이모지 |
| 얇은 회색 구분선으로 나눈 목록 | 카드마다 그림자·테두리 |
| 큰 사진 + 헤드라인의 기사 블록 | 둥근 모서리 남발 (4~12px만) |
| 회색 배경 띠로 섹션 구분 | 컬러 배경 버튼 |

## 2. 디자인 토큰

### 색 (IEA 실측값)

| 역할 | HEX | 용도 |
|---|---|---|
| 본문 텍스트 | `#000000` | **순수 검정.** 제목·본문 모두 |
| 보조 텍스트 | `#6F6F6F` | 날짜, 출처, 설명 |
| 3차 텍스트 | `#949494` | 비활성, 메타 |
| 배경 | `#FFFFFF` | 기본 |
| 섹션 배경 | `#F3F3F3` | 띠 형태로 섹션 구분 |
| 강조 배경 | `#F2F6FF` | 데이터·강조 패널 (아주 옅은 파랑) |
| 구분선 | `#E6E6E6` | 1px 가로선 |
| **강조색** | **`#0044FF`** | 링크, 활성 탭, 주요 액션. **유일한 강조색** |
| 다크 패널 | `#0B0B23` ~ `#000000` | 배너·푸터 등 반전 구간 |
| 경고·부정 | `#E34946` | 축소 신호, 오류 |

**밸류체인 3분류** — IEA 팔레트에 맞춰 채도를 낮춘다. 배경 없이 **텍스트 색 + 얇은 테두리 태그**로 표기:

| 분류 | 글자·테두리 |
|---|---|
| 셀사 | `#0044FF` |
| 양극재 | `#6F42C1` |
| 음극재 | `#A85B00` |

**신호 방향:** 확대 `#00875A` / 축소 `#E34946`.
**근거 등급:** 공시·검증 완료는 `#000000`, 보조(참고) 데이터는 `#949494`.

### 타이포그래피

- 서체: **`Graphik`** (없으면 `Pretendard`, `Inter`, `Arial`). 한 가족만 쓴다.
- 한국어 본문이 대부분이므로 한글 웨이트가 있는 대체 서체 필수.

| 요소 | 크기 | 굵기 | 자간 | 행간 |
|---|---|---|---|---|
| 페이지 제목 | 40px | 700 | −0.8px | 1.1 |
| 기사 헤드라인 | 24px | 700 | −0.48px | 1.33 |
| 섹션 제목 | 20px | 700 | −0.4px | 1.1 |
| 목록 제목 | 16px | 700 | 0 | 1.25 |
| 본문 | 15px | 400 | 0 | 1.6 |
| 메타·캡션 | 13px | 400 | 0 | 1.5 |
| 태그 | 12px | 400 | 0 | — |

- **제목은 항상 700**, 800·900을 쓰지 않는다. 크기와 자간으로 위계를 만든다.
- 수치는 `font-variant-numeric: tabular-nums`.

### 형태·간격

- 모서리: **4px(태그·버튼) / 8px(이미지·패널) / 100px(알약 태그) / 50%(아이콘 버튼)**. 그 외 금지.
- **그림자 없음.** 입체감은 배경색 차이로만.
- 카드 테두리도 기본적으로 없다. 구분은 **1px `#E6E6E6` 가로선**과 **회색 배경 띠**로.
- 본문 최대 폭 **1280px**, 좌우 여백 32px.
- 섹션 상하 여백 **64px**, 목록 항목 간 **20px + 구분선**.

## 3. 전역 구조

```
┌─ 상단바 (흰 배경, 76px) ───────────────────────────────────┐
│  CBL(로고)          Daily · 기업 분석 · 비교        🔍  ☰   │
└────────────────────────────────────────────────────────────┘
   본문 (최대 1280px 중앙 정렬)
```

- 로고: 워드마크만. 파랑(`#0044FF`) 소문자 로고타입 `cbl` 또는 `China Battery Lens`.
- 내비: 텍스트 링크. **활성 항목만 검정 700**, 나머지 `#6F6F6F` 400. 밑줄·배경 없음.
- 우측: 검색 아이콘, 메뉴 아이콘 (선 아이콘, 검정).
- 상단바 아래 1px `#E6E6E6` 선.
- 데이터 기준일은 상단바가 아니라 **첫 화면 제목 아래 메타 줄**로 옮긴다.

**진입 게이트:** 흰 화면 중앙에 로고 + 한 줄 설명 + 코드 입력 1개 + 파란 버튼. 테두리 없는 미니멀 폼.

## 4. 화면 1 — Daily

> IEA 첫 화면의 "Latest news, commentaries and reports" 구조를 그대로 빌린다.

### 4-1. 페이지 헤더
```
오늘의 중국 배터리 산업
2026년 9월 4일 기준 · 내부 검토용                    [수집·분석] [Excel] [새로 고침]
```
- 제목 40px/700, 그 아래 13px `#6F6F6F` 메타 한 줄
- 우측 버튼은 **테두리 없는 텍스트 버튼**(파랑) 또는 1px 검정 테두리 버튼. 채워진 버튼 금지.

### 4-2. Daily 리포트 — 리드 블록
- 섹션 제목 `Daily Report` 20px/700
- 카테고리별 목록. 각 카테고리는 **알약 태그**(1px 테두리, 12px)로 시작하고 그 아래 사실 목록
- 각 항목: `회사명 — 사실`. 회사명 700, 수치 700, 나머지 400
- 항목 사이 1px `#E6E6E6` 구분선

### 4-3. 해석 블록
- **배경 `#F2F6FF`** (옅은 파랑) 전체 폭 띠. 사실 영역(흰 배경)과 색으로 분리
- 안쪽: `해석` 태그 + "오늘의 그림" 20px/700 + 판단 문단
- 각 항목에 세그먼트 태그(셀/양극재/음극재/공급망/전반) + 하단 13px `#6F6F6F` "근거 · …"

### 4-4. Daily Top 10
- IEA 기사 목록 그대로: **첫 1건은 큰 사진 카드**(사진 없으면 회색 `#F3F3F3` 블록에 회사명 크게), 나머지는 텍스트 목록
- 각 항목: `[카테고리 태그]` → 헤드라인 24px/700 → 메타(회사 · 매체 · 날짜) → 1px 구분선
- Top 10 순위는 헤드라인 왼쪽에 회색 숫자로

### 4-5. 회사별 헤드라인 키워드 (Sankey)
- 섹션 배경 `#F3F3F3` 띠
- 좌측 기업 노드 / 우측 신호 노드, 곡선 연결
- 기업 노드: **흰 배경 + 1px 테두리 사각형**. 왼쪽에 밸류체인 태그(테두리형, 분류색 글자), 오른쪽에 회사명 검정 700
- 신호 노드: 확대 `#00875A` 테두리 / 축소 `#E34946` 테두리, 흰 배경
- 연결선: 건수 비례 두께, 확대 초록 / 축소 빨강, 투명도 0.5
- 12개사 초과 시 상단에 회색 배경 안내 줄

### 4-6. 회사별 뉴스
- 필터 줄: 밸류체인 탭(텍스트 탭, 활성만 검정 700 + 하단 2px 파란 선) + 회사 드롭다운 + 기간 2개 + 적용

## 5. 화면 2 — 기업 분석

### 5-1. 헤더
- 제목 "기업 시계열" 40px/700 + 메타 줄
- 우측: 텍스트 버튼 3개

### 5-2. 근거 질의응답
- 배경 `#F2F6FF` 띠
- 입력창은 **밑줄만 있는 라인 인풋**(테두리 상자 아님) + 파란 텍스트 버튼
- 답변: 본문 15px + 번호 매긴 출처 목록(숫자는 파랑, 링크는 검정 밑줄)

### 5-3. 회사 선택기
- 밸류체인 탭 + **회사 목록**. 칩 그리드 대신 **테이블에 가까운 목록**
- 각 행: 회사명 700 + 중국어명 `#6F6F6F` + 밸류체인 태그 + 순위. 행 사이 1px 구분선
- 선택된 행은 왼쪽에 3px 파란 세로 바

### 5-4. 회사 헤더
- **컬러 배너 대신** 큰 제목 블록: 회사명 40px/700, 그 아래 중국어·영어명 15px `#6F6F6F`, 그 아래 태그 줄(밸류체인, 그룹, 순위)
- 하단 1px 구분선

### 5-5. 연차보고서 핵심 사실
- 섹션 제목 + 우측 `거래소 공시 출처만` 텍스트 라벨(회색)
- 연도별 접이식. 펼침 표시는 `+`/`−` 기호
- 보고서 블록: 기간 700 + 근거종류·건수 `#6F6F6F` + 원문 링크(파랑)
- 본문은 **시장 / 기술 2열**. 열 제목은 12px 대문자 트래킹, 시장 `#0044FF` / 기술 `#A85B00`
- 각 사실은 한 줄 + 수치 강조. 4건 초과 시 "+N건" 텍스트 버튼

### 5-6. 시장·기술 레이어별 시간축
- 섹션 배경 흰색, 표는 **테두리 없는 표**. 행 구분은 1px `#E6E6E6` 가로선만
- 열: 시장 2묶음 / 시점 / 기술 2묶음
- 열 머리: 12px 대문자, 시장 파랑 / 기술 갈색, 아래 2px 색 밑줄
- 시점 열: 배경 `#F3F3F3`, 가운데 정렬, 700
- 셀: 사실 제목 검정 700 + 원문 링크. **보조 데이터는 `#949494` 400**
- 빈 셀 `—` `#949494`
- 우측 상단에 "보조 데이터 포함" 체크박스 + `?` 도움말

## 6. 화면 3 — 비교

```
기업A 기술 │ 기업A 시장 │  시점  │ 기업B 시장 │ 기업B 기술
```

- 상단: A 회사명 24px/700(좌) · "공통 시간축" 13px 회색(중앙) · B 회사명(우, 우측정렬)

- 축 라벨 줄: 기술 / 시장 / (빈칸) / 시장 / 기술 — 12px 대문자, 각 축 색
- 시간축: 세로 1px `#E6E6E6` 선 + **검정 원형 노드 10px** + 시점 텍스트 13px/700. **위가 최근**

### 6-3. 비교 리포트

## 7. 공통 컴포넌트

### 기사 목록 항목 (IEA 핵심 패턴)
```
┌────────────────────────────────────────────────┐
│ [카테고리 태그]                                 │
│ 헤드라인이 두 줄까지 들어가는 24px 굵은 제목    │
│ 회사명 · 매체 · 2026.09.03        [Top 10 · 3위]│
├────────────────────────────────────────────────┤   ← 1px #E6E6E6
```
- 태그: 1px `#E6E6E6` 테두리, radius 100px, 12px, 검정 글자, 흰 배경
- 헤드라인: 검정 700, hover 시 파랑
- 메타: 13px `#6F6F6F`
- Top 10 뱃지: 파란 테두리 + 파란 글자

### 태그 / 뱃지
- 기본형: **흰 배경 + 1px 테두리 + 검정 글자**. 채워진 배경은 쓰지 않는다
- 색 구분이 필요할 때만 테두리·글자에 색을 넣는다(밸류체인, 신호 방향)

### 버튼
- **1차:** 파란 글자(`#0044FF`) 텍스트 버튼 + 화살표 `→`. 배경 없음
- **2차:** 1px 검정 테두리, 흰 배경, 검정 글자, radius 4px
- 채워진 컬러 버튼은 진입 게이트 제출 버튼에만
- hover: 파랑으로 색만 변경. 이동·그림자 없음

### 탭
- 텍스트만. 활성은 검정 700 + 하단 2px `#0044FF`. 비활성 `#6F6F6F` 400

### 표
- 외곽 테두리·세로선 없음. **가로선만** 1px `#E6E6E6`
- 헤더: 12px 대문자, `#6F6F6F`, 하단 1px 검정 선
- 행 hover 시 배경 `#F3F3F3`

### 도움말
- 12px 원형 `?`, 테두리형. hover 시 **검정 배경 흰 글자 툴팁**(radius 4px, 13px)

### 진행 표시
- 오버레이 대신 **상단 2px 파란 진행 바** + 버튼 자리에 "분석 중 · 42초 경과" 텍스트

## 8. 반드시 지킬 원칙

1. **강조색은 파랑 하나.** 그 외 색은 의미가 있을 때만(밸류체인 3색, 확대/축소 2색, 오류 1색).
2. **사실과 해석을 배경색으로 분리.** 사실=흰색, 해석=`#F2F6FF`. 섞이면 제품 원칙 위반.
3. **신뢰 등급이 보인다.** 공시·검증 완료=검정, 보조 데이터=`#949494`.
4. **시장=파랑 / 기술=갈색** 축 색은 모든 화면에서 동일.
5. **그림자와 채워진 카드 금지.** 구분은 선과 배경 띠로만.
6. **밀도를 유지한다.** 여백을 키워 스크롤을 늘리지 않는다. IEA도 목록은 촘촘하다.
7. **수치는 tabular-nums**, 모든 사실에는 원문 링크.
8. **한국어가 본문**, 중국어·영어는 작게 보조.

## 9. Stitch 프롬프트 (복사용)

> 중국 배터리 산업 리서치 대시보드. **IEA(iea.org) 스타일의 기관 리서치 퍼블리케이션** 톤 — 흰 바탕, 순수 검정 활자, 강조는 파랑 `#0044FF` 하나. 그림자·그라데이션·채워진 컬러 카드 없음.
>
> 색: 배경 `#FFFFFF`, 섹션 띠 `#F3F3F3`, 강조 패널 `#F2F6FF`, 구분선 `#E6E6E6`, 본문 `#000000`, 보조 텍스트 `#6F6F6F`, 3차 `#949494`, 강조 `#0044FF`, 경고 `#E34946`.
> 서체 Graphik(대체 Pretendard/Inter). 제목 700, 자간 −0.4~−0.8px. 페이지 제목 40px, 헤드라인 24px, 섹션 20px, 본문 15px, 메타 13px, 태그 12px.
> 모서리 4px·8px·100px만. 카드 테두리·그림자 없이 1px `#E6E6E6` 가로선과 회색 배경 띠로 구분.
> 상단바 76px 흰 배경, 좌측 워드마크, 가운데 텍스트 탭 3개(활성만 검정 700 + 2px 파란 밑줄), 우측 검색·메뉴 아이콘.
> 본문 최대 1280px 중앙 정렬, 섹션 간 64px.
>
> 세 화면:
> (1) **Daily** — 큰 제목 + 메타 줄, 카테고리 태그가 붙은 사실 목록, 옅은 파랑 배경의 해석 블록, 그 아래 IEA식 기사 목록(카테고리 알약 태그 → 24px 굵은 헤드라인 → 회색 메타 → 가로 구분선), 회색 띠 안에 기업↔키워드 Sankey 흐름도.
> (2) **기업 분석** — 회사 목록 테이블(선택 행 왼쪽 3px 파란 바), 회사명 큰 제목 블록, 연도별 접이식 보고서 요약(시장/기술 2열), 테두리 없는 시장·기술 매트릭스 표(가로선만).
> (3) **비교** — 가운데 세로 시간축을 두고 좌우 대칭 5열(A기술·A시장·시점·B시장·B기술), 검정 원형 노드, 셀은 배경 없이 가로선으로만 구분.
>
> 태그는 전부 흰 배경 + 1px 테두리형. 버튼은 파란 텍스트 버튼 또는 검정 테두리 버튼. 채워진 컬러 버튼 없음.
