# China Battery Lens — 디자인 명세 (Stitch 입력용)

Stitch 등 UI 생성 도구에 붙여 넣어 화면을 재현·재설계할 때 쓰는 문서다.
현재 배포된 화면(`app/index.html`, `app/styles.css`)에서 그대로 옮겼다.

---

## 1. 제품 한 줄 정의

중국 배터리 셀·양극재·음극재 기업의 뉴스와 거래소 공시를 수집해, **한국어 팩트 리포트·기업 시계열·기업 비교**로 보여주는 **내부 리서치 도구**. 사용자는 한국 배터리·소재 회사의 전략/기획 담당자다. 공개 서비스가 아니라 소수가 매일 들여다보는 대시보드다.

**톤:** 금융 리서치 터미널에 가깝다. 화려한 마케팅 랜딩이 아니라 **밀도 높고 조용한 업무 화면**. 정보가 주인공이고 장식은 최소.

## 3. 전역 구조

```
┌─ 상단바 (68px, sticky) ────────────────────────────────┐
│  [CB] China Battery Lens   Daily | 기업 분석 | 비교   데이터 기준 2026.09.04 · 내부 검토용 │
└────────────────────────────────────────────────────────┘
   본문 (최대 1240px 중앙 정렬, 탭으로 3개 화면 전환)
```

- 로고: 30×30 남색 라운드 사각형에 `CB` 흰 글자 + 워드마크.
- 내비: 3개 탭. 활성 탭은 남색 굵은 글씨 + 하단 3px 파란 밑줄.
- 우측 끝: 데이터 기준 날짜 (12px, `--muted`). 모바일에서는 숨김.

**진입 게이트:** 앱 진입 전 전체 화면 로그인. 중앙 카드에 `PRIVATE ACCESS` eyebrow + 제품명 + 접근 코드 입력 1개 + 버튼. 실패 시 카드 안에 빨간 안내문.

## 4. 화면 1 — Daily (첫 화면)

> 오늘 중국 배터리 산업에 무슨 일이 있었는지 한 장으로.

### 4-1. 페이지 헤딩
- 좌: eyebrow `DAILY INTELLIGENCE` + h1 "오늘의 중국 배터리 산업" + 한 줄 설명
- 우: 버튼 3개 (`수집·분석 1회 실행` / `Raw data Excel` / `새로 고침`) — 모두 흰 배경 + 테두리형(secondary)

### 4-2. Daily 리포트 카드
- 헤더: eyebrow `DAILY REPORT` + h2 + 우측에 "지난 리포트" **날짜 드롭다운 + 새 탭에서 열기 버튼**
- 본문: **카테고리별 개조식 목록**. 카테고리 칩(산업 총평 / 셀 / 양극재 / 음극재 / 정책·공급망)은 알약형, 카테고리마다 색이 다름.
- 각 항목: `회사명 — 사실 문장`. 회사명은 남색 굵게, 수치는 남색 굵게 강조.

### 4-3. 해석 블록 (사실과 시각적으로 분리)
- 배경 `#fffdf6`, 테두리 `#e4dcc8` (따뜻한 톤) — **사실 영역과 다른 색으로 반드시 구분**
- eyebrow는 기술색(`--tech`), 제목 "오늘의 그림"
- 각 항목: 세그먼트 칩(셀/양극재/음극재/공급망/전반) + 판단 문단 + 하단에 작은 글씨 "근거 · …"

### 4-4. Daily Top 10
- 구분선 위에 eyebrow `근거 뉴스 · DAILY TOP 10`
- **뉴스 카드** 반복 (아래 공통 컴포넌트 참조)

### 4-5. 회사별 헤드라인 키워드 (Sankey 흐름도)
- eyebrow `HEADLINE KEYWORDS` + h2
- 좌측 **기업 노드**, 우측 **신호 노드**, 사이를 곡선으로 연결
- 기업 노드는 **두 개의 분리된 상자**: 좁은 밸류체인 칩(52px, 분류색) + 회사명 상자(186px, 연파랑)
- 신호 노드: 확대 상위 4개(연초록 배경) / 축소 상위 4개(연빨강 배경), `키워드 · N건`
- 연결선 두께는 건수 비례, 색은 확대 초록 / 축소 빨강, 투명도 0.58
- 기업이 12개를 넘으면 상위만 표시하고 **위에 안내 배너**: "신호가 잡힌 28개사 중 출하 순위 상위 12개사만 표시합니다…"
- 상단 컨트롤: 기간 시작/끝 날짜 + 적용 버튼

### 4-6. 회사별 뉴스
- eyebrow `COMPANY NEWS` + h2
- 필터 줄: **밸류체인 세그먼트 컨트롤**(셀사/양극재/음극재) + 회사 드롭다운 + 기간 시작/끝 + 적용 버튼
- 뉴스 카드 반복

## 5. 화면 2 — 기업 분석

### 5-1. 헤딩
- eyebrow `COMPANY LENS` + h1 "기업 시계열"
- 우측 버튼: `시계열 백필 1회 실행`, `벡터DB 임베딩 채우기`, `Excel 내보내기`

### 5-2. 근거 질의응답 패널
- eyebrow `EVIDENCE SEARCH` + h2 "수집된 근거에 물어보기"
- 입력창 + 전송 버튼 한 줄, 우측에 "이 회사만" 체크박스
- 답변 영역: 답변 문단 + 하단에 번호 매긴 출처 목록(원형 번호 뱃지 + 링크)

### 5-3. 회사 선택기
- 밸류체인 탭(개수 뱃지 포함) + **회사 칩 그리드**
- 칩: 34×34 이니셜 마크 + 회사명 + 메타(순위·태그). 선택 시 남색 테두리 + 연파랑 배경
- 그리드 `minmax(198px, 1fr)` 자동 채움

### 5-4. 회사 프로필 배너
- **남색 꽉 찬 배경**, 흰 글자, radius 13px
- 좌: 밸류체인 eyebrow(밝은 파랑) + 회사명 h2 + 중국어/영어명 + 그룹 계열사
- 우: 반투명 테두리 뱃지들 (그룹명, "출처 확인 이벤트만 표시")

### 5-5. 연차보고서 핵심 사실
- eyebrow `ANNUAL REPORT DIGEST` + h2, 우측에 "거래소 공시 출처만 채택" 알약 라벨
- **연도별 접이식(details)**. 최근 연도만 펼침
- 연도 안에 **보고서 카드** 반복: 헤더(기간·근거종류·사실 수·원문 링크) + 본문을 **시장 / 기술 2열**로 분할
- 각 열: 소제목(시장=파랑, 기술=갈색) + 개수 + 사실 목록. 4건 넘으면 "+N건 더보기" 버튼

### 5-6. 시장·기술 레이어별 시간축
- eyebrow `MARKET × TECHNOLOGY` + h2, 우측에 **"보조 데이터 포함" 체크박스 + ? 도움말 아이콘**
- 범례 줄: ● 시장 / ● 기술 / "위가 최근 · 아래가 과거"
- **표 형태 매트릭스**: 열 = 시장 2묶음(실적·생산기반 / 고객·해외) + 시점 + 기술 2묶음(소재·공정 / IP·인증·양산)
- 열 머리 위에 트랙 배너(시장=연파랑, 기술=연노랑)
- 시점 열은 좁고 회색 배경, 가운데 정렬, 굵은 남색
- 셀 내부: 사실 제목(굵게) + 원문 링크. **보조 데이터는 흐린 회색 + 보통 굵기**로 구분
- 빈 셀은 `—` 회색

## 6. 화면 3 — 비교

### 6-1. 헤딩
- eyebrow `COMPANY COMPARISON` + h1 "기업 비교"

### 6-2. 컨트롤 (가로 한 줄)
- 기업 A: 밸류체인 세그먼트 + 회사 드롭다운
- 기업 B: 동일
- `비교 리포트 생성` 버튼
- "보조 데이터 포함" 체크박스 + ? 아이콘

### 6-3. 비교 매트릭스 (핵심 화면)
**5열 대칭 구조**, 가운데 시간축을 두고 좌우가 마주봄:

```
기업A 기술 │ 기업A 시장 │ ● 시점 ● │ 기업B 시장 │ 기업B 기술
   (우측정렬)   (우측정렬)   (중앙)     (좌측정렬)   (좌측정렬)
```

- 상단: A 회사명(좌) / "공통 시간축"(중앙) / B 회사명(우, 우측정렬). 각 회사 아래 커버리지 메모("공시 6건 · 이벤트 21건 · 2023년~")
- 그 아래 축 라벨 줄: 기술 / 시장 / (빈칸) / 시장 / 기술 — 각각 트랙색
- 시간축: 세로선 + 남색 원형 노드(14px, 연파랑 3px 테두리) + 시점 텍스트. **위가 최근**
- 각 셀: 최대 3건, 흰 배경 + 테두리. 항목마다 불릿 + 제목 + 핵심 수치. 3건 초과 시 "+N건"
- 근거 두께가 2배 이상 차이 나면 상단에 **경고 배너**
- 가로 스크롤 허용(최소 폭 1080px)

### 6-4. 비교 리포트
- 생성 후 아래에 **접이식 패널**로 인라인 표시. 헤더에 제목 + `PDF로 저장` / `닫기` 버튼
- 리포트 본문 구성: 헤드라인 → **① 회사별 궤적 분석**(A/B 2열, 각 열에 시장·기술 태그) → **② 궤적 비교**(시장/기술/갈린 지점) → **③ 한국 관점 해석** → **④ 웹 검증**
- 그 위에 **지난 비교 리포트 목록**(접이식): 날짜 · A vs B · [공시만/보조 포함] · 헤드라인

## 7. 공통 컴포넌트

### 뉴스 카드
```
┌──────────────────────────────────────────────┐
│ [회사 칩]          │ 제목 (h3)                │
│ [검증 태그]        │ • 사실 불릿              │
│ 2026.09.03         │ • 사실 불릿              │
│                    │ 출처: 매체명   👍 👎 원문↗ │
└──────────────────────────────────────────────┘
```
- 좌측 130px 고정 열 + 우측 가변 열, 간격 18px
- 회사 칩: 연파랑 알약. 여러 회사면 `A · B`로 이어 표시
- 검증 태그: 초록 알약 "본문대조 완료"
- Top 10에도 오른 기사는 **남색 알약 "Top 10 · 3위"** 추가
- 사실은 불릿 목록, 최대 78자 폭
- 하단: 좌측 출처, 우측 좋아요/싫어요 + 원문 링크
- 모바일에서는 1열로 무너지고 좌측 열이 가로 배치로 전환

### 세그먼트 컨트롤
- 테두리 있는 알약 컨테이너 안에 버튼 3개
- 선택된 것만 남색 배경 + 흰 글자 + 굵게, 나머지는 투명 배경 + 회색 글자

### 버튼
- **secondary(기본)**: 흰 배경, 1px `--line` 테두리, radius 7px, 남색 글자 650 굵기, hover 시 연파랑 배경
- 화면에 primary 버튼은 없다. 모든 액션이 동등한 무게.

### 도움말 아이콘
- 15×15 원형, 연파랑 배경 + 파란 `?`. hover/focus 시 파란 배경 + 흰 글자
- 마우스 올리면 **어두운 남색 툴팁**(최대 340px, 반투명 배경, 흰 글자 12px)이 커서 옆에 뜸

### 진행 오버레이
- 수십 초 걸리는 작업 중 전체 화면 반투명 남색 + blur
- 중앙 흰 카드: 3중 회전 링(파랑/초록/갈색) + 제목 + 진행 문구 + 경고 문구

## 8. 재설계 시 반드시 지킬 원칙

1. **사실과 해석을 시각적으로 분리한다.** Daily 리포트의 사실 영역과 해석 영역은 배경·테두리 색이 달라야 한다. 섞이면 제품 원칙 위반이다.
2. **신뢰 등급이 보여야 한다.** 거래소 공시·검증 통과 사실은 진하게, 보조(참고) 데이터는 흐리게. 색과 굵기 둘 다로 구분.
3. **시장 축과 기술 축은 항상 같은 색 체계.** 시장=파랑 계열, 기술=갈색/노랑 계열. 화면이 바뀌어도 유지.
4. **수치는 tabular-nums.** 표·목록에서 자릿수가 흔들리면 안 된다.
5. **밀도를 낮추지 말 것.** 한 화면에 많은 정보를 담는 게 목적이다. 여백을 키워 스크롤을 늘리는 방향은 반대다.
6. **한국어가 본문이다.** 중국어·영어는 근거·검색용으로만 작게 노출.
7. **모든 사실에는 원문 링크가 붙는다.** 링크 없는 주장은 화면에 올리지 않는다.

## 9. Stitch 프롬프트 요약본

> 중국 배터리 산업 리서치 대시보드. 금융 터미널 톤의 조용하고 밀도 높은 내부 도구.
> 배경 `#f5f7fa`, 카드 흰색 radius 12px 테두리 `#dbe3ec`, 주색 남색 `#10365f`, 강조 파랑 `#1674c5`.
> 서체는 Noto Sans KR, 본문 13px, h1 32px, 작은 대문자 eyebrow 라벨 11px 파랑.
> 상단 68px 고정 바에 로고 + 3탭(Daily / 기업 분석 / 비교) + 우측 데이터 기준일.
> 최대 폭 1240px 중앙 정렬. 760px 이하 1열.
> 세 화면: (1) 일간 리포트 + 카테고리 요약 + 해석 블록(따뜻한 베이지 배경) + 뉴스 카드 목록 + 기업↔키워드 Sankey 흐름도,
> (2) 기업 시계열 — 남색 프로필 배너 + 연도별 접이식 보고서 요약 + 시장/기술 2×2 매트릭스 표,
> (3) 기업 비교 — 가운데 세로 시간축을 두고 좌우 대칭 5열(A기술·A시장·시점·B시장·B기술).
> 밸류체인 3색: 셀사 남색 `#cfe0f2`, 양극재 보라 `#e2d9f3`, 음극재 갈색 `#f7e3c4`.
