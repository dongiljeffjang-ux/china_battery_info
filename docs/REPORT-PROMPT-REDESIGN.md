# 기업 시계열 분석 보고서 프롬프트 개편안

작성일: 2026-09-11  
상태: 2026-09-11 세 보고서 분리안을 폐기하고 통합 보고서로 구현.

## 현재 결정: 하나의 시계열 보고서

시계열에 있는 약 40~50개 팩트를 세 개의 짧은 보고서에 나누지 않는다. 한 보고서가 같은 근거를 한 번 읽고 다음 순서로 결론을 연결한다.

1. **전략의 현재 위치와 변화:** 비교 가능한 과거와 현재를 바탕으로 유지·확장·중심 이동을 구분한다.
2. **반복해서 나타난 실행 방식:** 서로 독립된 사례 두 개 이상에서 같은 구체적 선택이 확인될 때만 쓴다. 성립하지 않으면 절을 뺀다.
3. **판단을 바꿀 핵심 변수:** 현재 사실·중요한 이유·관측 가능한 후속 신호를 쓴다. 근거가 약한 두 갈래 시나리오는 만들지 않는다.
4. **한국 배터리·소재사에 주는 의미:** 위 분석을 반복하지 않고 관련 사업에 미치는 방향만 정리한다.

입력은 일반적인 기업 시계열 40~50건을 그대로 사용하고, 48건을 넘을 때만 연도·레이어·기술 축을 보존해 압축한다. 기존의 기준 시점 대비표·사업선별 사건 순서·진행 상태표는 모두 한 입력에 들어가지만, 기계적 읽기 보조자료일 뿐 독립된 근거로 취급하지 않는다.

아래 내용은 3종 분리안을 만들 때의 설계 기록이다. 현재 제품 동작에는 적용하지 않는다.

## 이전 설계 기록: 3종 분리안

### 1. 개편 목표

같은 사실을 서로 다른 분석 결과로 변환한다. 사실의 중복을 피하는 것보다, 각 보고서가 답하는 질문과 결론의 성격을 구분하는 것이 중요하다.

| 보고서 | 핵심 질문 | 분석 단위 | 독자가 얻는 것 |
| --- | --- | --- | --- |
| 전략 방향 | 무엇이 유지되고, 무엇이 확장되거나 중심이 이동했는가? | 비교 가능한 과거와 현재 | 현재의 전략적 위치와 변화 |
| 패턴 인사이트 | 여러 사업에서 어떤 선택과 행동이 반복되는가? | 독립된 사례들의 공통 구조 | 사업을 전개하는 방식 |
| 전략 분기점 | 어떤 조건이 다음 전략적 경로를 바꾸는가? | 현재 근거·분기 조건·전략적 결과 | 경로를 판별할 관측 신호 |

전략 방향은 **변화**, 패턴 인사이트는 **반복 행동**, 전략 분기점은 **미래 조건**을 결론으로 삼는다. 다른 모드의 분석을 배경으로 짧게 활용할 수 있지만, 본문의 중심 논점은 선택한 질문에 답해야 한다.

## 2. 공통 생성 지시문 초안

```text
너는 중국 이차전지 산업 분석가다. 독자는 한국 배터리 셀·양극재·음극재 기업의 전략·시장·기술기획 담당자다.
제공된 사실을 선택한 보고서의 질문에 맞게 해석하고, 그 해석이 사업적으로 무엇을 뜻하는지 짧게 설명한다.

[근거와 해석]
- 입력에 있는 사실·수치·시점·출처만 사실로 사용한다. 새로운 사건·거래·고객·실적을 만들지 않는다.
- 해석은 이를 뒷받침하는 사실과 함께 쓴다. 제목과 핵심 요약의 주장도 본문 근거의 범위를 넘지 않는다.
- 확인된 사실을 연결해 사업적 의미를 추론할 수 있다. 사건의 선후만으로 인과관계를 단정하지 않는다.
- 계획, 착공, 가동, 출하, 매출을 구분한다. 계약·협력·고객 인증을 실제 판매로 격상하지 않는다.
- 자료가 없는 기간을 활동 중단으로 해석하지 않는다. 관측되지 않은 단계를 채워 넣지 않는다.
- 비교 대상이 없으면 업계 대비 우위나 기업만의 고유성을 주장하지 않는다.
- 근거가 약한 논점은 결론의 범위를 좁히거나 제외한다. 유보·면책 문장을 반복해 분량을 채우지 않는다.
- 조건부 해석에서는 조건을 생략하지 않는다. '반복 주문이 이어지면' 같은 표현은 분석에 필요한 조건이다.

[수치와 시간]
- 발표일, 사건 발생일, 실적 대상 기간을 구분한다.
- 같은 기간·단위·집계 범위끼리 비교한다. 연간과 반기의 절대값을 직접 비교하거나 임의로 연율화하지 않는다.
- 직접 계산한 값은 계산임을 표시한다. %와 %p를 구분한다.
- 두 시점만으로 가속·둔화를 단정하지 않는다.

[분량과 표현]
- 본문은 A4 한 장 분량을 목표로 간결하게 쓴다. 근거 목록은 별도로 둔다.
- 제목 바로 아래 핵심 요약을 3~4줄 쓴다. 각 줄은 결론을 먼저 쓰고 이를 지지하는 시점·수치 또는 구체적인 사실을 담는다.
- 요약의 각 줄은 다른 논점을 다룬다. 근거가 적으면 3줄로 쓰며, 줄 수를 채우기 위해 논점을 만들지 않는다.
- 본문 분석 항목은 최대 3개다. 성립하는 항목이 하나면 하나만 쓴다.
- 핵심 요약은 본문의 결론을 압축한다. 본문은 근거와 설명을 더하며 요약 문장을 그대로 반복하지 않는다.
- 한국 사업에 주는 의미는 관련 있는 셀·양극재·음극재 부문에 한정한다. 모든 부문에 억지로 함의를 붙이지 않는다.
- '지켜봐야 한다', '대응해야 한다' 같은 행동 지시 대신, 어떤 변화가 어떤 사업 조건을 바꾸는지 설명한다.
- 투자 추천·주가 전망·기업 홍보 표현을 쓰지 않는다.
- 한국어로 쓰고 제공된 표준 회사명을 사용한다. 내부 분류명과 식별자는 본문에 노출하지 않는다.
- 정책을 인용할 때는 적용 대상·시점과 해당 기업의 사건을 연결한다. 정책 번호에는 한국어 설명을 붙인다.

[출력]
- 선택한 모드의 출력 구조를 따른다. 근거 없는 항목은 제외한다.
- Markdown 보고서만 반환한다.
- 마지막 '근거'에는 본문에 사용한 사실의 시점·내용·출처를 적는다. 제공된 원문 링크를 보존한다.
```

## 3. 전략 방향 프롬프트 초안

```text
[전략 방향]
질문: 과거와 비교해 무엇이 유지됐고, 무엇이 확장됐으며, 자원과 사업의 상대적 무게는 어디로 이동했는가?

[분석 방법]
1. 비교 가능한 과거와 현재를 고른다. 오래된 사건과 최근 사건이라는 이유만으로 서로 다른 사업·집계 범위를 직접 대비하지 않는다.
2. 제품·화학계, 고객, 지역, 투자·생산, 매출·출하에서 의미 있는 변화 축을 고른다.
3. 각 축을 다음 중 근거에 맞는 성격으로 설명한다.
   - 유지: 기존 주력과 우선순위가 이어진다.
   - 확장: 기존 사업에 새로운 제품·지역·고객·역량이 더해진다.
   - 중심 이동: 비교 가능한 비중이나 자원 배분의 변화가 확인된다.
4. 신규 사업 진입만으로 중심 이동을 선언하지 않는다. 매출·출하·투자·생산능력 등의 상대적 변화 또는 명시적인 자원 재배분 결정을 근거로 삼는다.
5. 투자 계획의 재배분과 실제 매출 구조의 변화를 구별한다. 무엇의 중심이 이동했는지 명시한다.
6. 변화와 함께 기존 주력이 유지되는 근거도 반영한다. 기업 전체가 전환했다는 결론을 미리 정하지 않는다.

[출력 구조]
```

## 4. 패턴 인사이트 프롬프트 초안

```text
[패턴 인사이트]
질문: 이 기업은 서로 다른 사업이나 상황에서 어떤 선택을 반복하며, 그 선택은 사업 전개 방식에 어떤 특징을 만드는가?

[분석 방법]
1. 사건을 제품·공장·지역·프로젝트 등 실질적인 사례 단위로 묶는다.
2. 독립된 사례 두 개 이상을 비교해 반복되는 선택이나 행동 구조를 찾는다.
3. 같은 프로젝트의 착공·인증·출하는 하나의 사례다. 이를 세 개의 독립 사례로 세지 않는다. 같은 사건의 여러 기사도 하나로 센다.
4. '개발 → 생산 → 출하'처럼 제조업의 일반적인 진행 순서만으로 패턴을 만들지 않는다. 투자와 고객 확보의 순서, 합작과 자체 투자의 선택, 생산기반 활용 방식 등 구체적인 선택을 설명한다. 이 예시가 입력에 없으면 사용하지 않는다.
5. 각 사례에서 실제로 확인된 단계만 비교한다. 한 사례의 빈 단계를 다른 사례로 채우지 않는다.
6. 공통 행동과 어긋나는 사례가 입력에 있으면 이를 반영해 패턴의 적용 범위를 좁힌다. 일부 사업의 방식을 기업 전체의 원리로 확대하지 않는다.
7. 반복 관측은 기업 고유성이나 성공 원인의 증명이 아니다. 경쟁사 근거 없이 '이 회사만의 방식'이라고 쓰지 않는다.
8. 성립하는 패턴만 최대 3개 쓴다. 한 사업의 진척 요약으로 항목을 채우지 않는다.

[출력 구조]
# 패턴 인사이트: (반복되는 구체적인 행동을 담은 제목)

## 핵심 요약
3~4줄. 반복 행동 → 이를 보여 주는 독립 사례 → 사업적 의미.

## 패턴 1: (어떤 상황에서 어떤 선택을 반복하는지 담은 제목)
반복 행동을 한 문장으로 설명한다.

| 독립 사례 | 확인된 선택·진행 (시점·사실) | 공통 구조 |
최소 두 사례를 비교한다. 존재하지 않는 단계를 보완하지 않는다.

이 방식이 사업 전개에 주는 의미를 두세 문장으로 설명한다. 적용 범위를 바꾸는 예외가 있으면 함께 반영한다.

필요한 경우 패턴 2~3을 같은 구조로 쓴다.

## 한국 사업에 주는 의미
반복 행동으로부터 설명할 수 있는 공급·고객·상용화 관련 의미를 1~2개 쓴다.

## 근거
```

패턴이 하나도 성립하지 않으면 진척 요약을 패턴으로 대체하지 않는다. 이 경우에는 정상 보고서를 억지로 생성하기보다 “현재 선택된 근거에서는 독립 사례 간 반복 행동이 성립하지 않습니다.”라는 짧은 결과를 반환하는 방안을 제안한다. 이는 기존의 유보 문장 반복 금지와 구별되는 **생성 가능 여부 안내**이며, 구현 시 별도 결과 상태로 다루는 것이 적절하다. 이 예외에서는 핵심 요약 3~4줄 형식을 적용하지 않는다.

## 5. 전략 분기점 프롬프트 초안

```text
[전략 분기점]
질문: 현재 확인된 움직임에서 어떤 조건이 향후 기업의 역할·자원 배분·고객 기반을 달라지게 하는가?

[분석 방법]
1. 최신 사실로 현재 위치를 정한다. 과거의 계획이 후속 사건에서 완료·변경됐는지 먼저 확인한다.
2. 현재 사업과 직접 연결되는 조건 중, 충족 여부에 따라 전략적 결과가 달라지는 조건을 고른다.
3. 두 경로는 기업의 역할, 투자 우선순위, 고객 기반, 공급 방식 등에서 실질적인 차이가 있어야 한다.
4. 단순 가동·지연 또는 성공·실패만으로 분기를 만들지 않는다. 일정 차이가 전략적 결과를 바꾼다면 그 연결을 설명한다.
5. 각 경로에 조건, 관측 가능한 신호, 기업에 주는 결과를 연결한다. 한국 사업에 대한 의미도 이 경로에서 직접 도출한다.
6. 반복 주문·고객 채택·증설 결정 등을 미래 조건으로 제시할 수 있다. 입력에 없으면 이미 발생한 사실처럼 쓰지 않는다.
7. 신호가 아직 보이지 않는다는 이유로 반대 경로가 확정됐다고 쓰지 않는다. 반대 경로도 축소 결정·용도 변경·투자 유지 등 실제로 판별 가능한 근거를 설명한다.
8. 임의의 성공 확률, 미래 매출, 수치 기준, 관측 기한을 만들지 않는다. 공개된 목표가 있으면 목표임을 밝힌다.

[출력 구조]
# 전략 분기점: (전략적으로 무엇이 갈리는지 담은 제목)

## 핵심 요약
```

## 7. 입력 구성에서 함께 바꿀 부분

프롬프트만 바꾸면 기존 입력 보조표가 이전 분석 방식을 계속 유도할 수 있다.

| 현재 구성 | 변경안 | 이유 |
| --- | --- | --- |
| 전략 방향: 축별 가장 오래된 연도와 최근 연도 사건 대비 | 비교 후보임을 명시하고 제품·기간·집계 범위의 비교 가능성을 먼저 판단하도록 변경 | 다른 대상의 사건을 중심 이동 근거로 사용하는 문제 방지 |
| 패턴: 단어가 겹치는 사건 쌍을 분석 출발점으로 지정 | 원 사건 표에서 독립 사례를 먼저 묶어 비교. 기존 사건 쌍은 패턴의 증거로 취급하지 않음 | 같은 사업의 진행 사슬에 고정되는 문제 해소 |
| 분기점: 계획·착공·인증 어휘가 있는 사건 우선 | 후속 사실까지 읽어 현재 상태를 판단. 초기 출하·가동 이후에도 전략적 분기가 남을 수 있음을 반영 | 완료된 옛 계획과 현재 분기의 혼동 방지 |

첫 구현에서는 추가 LLM 호출 없이 기존 생성 호출 안에서 사례 비교와 현재 상태 판정을 수행하는 방향을 제안한다. 입력 선별이 필요한 사례를 누락시키는지는 실제 입력을 확인한 뒤 조정한다. 근거 건수 확대를 먼저 전제하지 않는다.

## 8. 검증 기준

동일한 원천 자료와 기준일로 세 모드를 생성하고, 실제로 모델에 전달된 근거도 함께 남겨 비교한다.

1. 제목을 가려도 변화·반복 행동·미래 조건 중 어떤 분석인지 구별되는가?
2. 전략 방향은 신규 사업 추가와 실제 중심 이동을 구분하는가?
3. 패턴마다 독립 사례가 최소 두 개 있는가? 일반적인 공정 순서 이상의 구체적인 선택을 설명하는가?
4. 분기점의 두 경로는 일정 외에 기업의 역할이나 자원 배분에서 차이가 있는가?
5. 미래 조건이 이미 발생한 사실로 쓰이거나, 빈 단계가 만들어지지 않았는가?
6. 요약은 본문의 결론을 정확히 압축하고, 항목 수를 채우기 위한 중복이 없는가?

세 모드가 같은 사실을 인용하는 것은 감점하지 않는다. 같은 결론을 제목과 형식만 바꿔 반복하는지를 평가한다. 독립 사례가 부족한 입력도 포함해 패턴을 억지로 생성하지 않는지 확인한다.

## 9. 적용 범위

대상은 기업 시계열 보고서의 전략 방향·패턴 인사이트·전략 분기점 세 모드다. 기업 간 비교 보고서와 Daily 프롬프트는 이번 개편의 직접 대상이 아니다.

구현 시에는 모드 지시문, 모드별 입력 읽기 지시, 입력 보조표의 역할을 함께 정렬한다. 기존의 사실 보존·출처 유지·한국어 표시 원칙을 유지한다. 조건부 표현이 후처리에서 사라지지 않는지도 확인한다.
